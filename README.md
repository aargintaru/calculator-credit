# 📊 Calculator Avansat Credit Ipotecar & Punct de Inflexiune

Un instrument web interactiv, modern și ușor de utilizat, conceput pentru analiza detaliată a unui credit ipotecar, vizualizarea evoluției soldului în timp și identificarea momentului exact în care componenta de principal depășește dobânda.

Proiectul este construit folosind tehnologii web native (HTML5, CSS3, JavaScript) și folosește biblioteca **Chart.js** pentru randarea graficelor dinamice. Este optimizat pentru a fi găzduit gratuit prin **GitHub Pages**.

---

## 🚀 Funcționalități principale

- **Sincronizare bidirecțională:** Fiecare parametru poate fi ajustat rapid fie prin intermediul sliderelor interactive, fie introducând valoarea exactă într-o căsuță numerică dedicată.
- **Calculul Punctului de Inflexiune:** Algoritmul simulează evoluția creditului lună de lună pentru a detecta exact _luna și anul_ în care rata lunară conține mai mult principal decât dobândă.
- **Grafic dinamic în timp real:** Vizualizează scăderea soldului creditului de-a lungul orizontului de timp selectat.
- **Design Responsive & Modern:** Interfață curată, adaptată atât pentru ecrane mari de desktop, cât și pentru telefoane mobile.
- **100% Offline-capable:** Funcționează local în orice browser web, fără a necesita server dedicat.
